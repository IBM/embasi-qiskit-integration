Using the quantum pipeline

How integrals become an energy on this branch, and which arrows this PR moved. Orange marks what changed.

The pipeline

Using it

The one-call path — SQDSolver drives every box above:

from embasi_qiskit_integration.hamiltonian import fcidump
from embasi_qiskit_integration.circuit_run.aer import AerSampler
from embasi_qiskit_integration.solvers import SQDSolver

ham = fcidump.read("tests/data/n2_8o10e.fcidump")

# exact evolution, one circuit
res = SQDSolver(AerSampler(), shots=100_000, seed=24).solve(ham)

# qDRIFT ensemble: 4 circuits x 5k shots, counts pooled
res = SQDSolver(AerSampler(), shots=5_000, seed=24,
                method="qdrift", num_randomizations=4).solve(ham)

res.energy                      # -108.9585 Ha
res.diagnostics["n_circuits"]   # 4
res.diagnostics["n_shots"]      # 20000

Or drive the stages yourself — build_circuits() is public, so you can inspect or re-target exactly what solve() would sample:

from embasi_qiskit_integration.circuit_run import merge_counts

solver   = SQDSolver(AerSampler(), shots=5_000, seed=24,
                     method="qdrift", num_randomizations=4)
circuits = solver.build_circuits(ham)          # N full circuits (prep + core)
counts   = solver.sampler.run(circuits, 5_000, seed=24)   # N counts dicts
pooled   = merge_counts(counts)                # 20_000 shots

Swapping the sampler is the only change needed to move between simulation, replay, and hardware:

from embasi_qiskit_integration.circuit_run import build_sampler

build_sampler("aer")                                    # local, noiseless
build_sampler("mock", counts="tests/data/mock_counts.json")   # frozen replay
build_sampler("runtime", backend="FakeManilaV2")        # offline device rehearsal
build_sampler("runtime")                                # real hardware, least-busy
On hardware, enable measurement twirling — RuntimeSampler(options={"twirling": {"enable_measure": True}}). Readout error flips a bit, which changes a determinant's Hamming weight, so SQD postselects that shot away: it wastes budget and biases the surviving subspace, moving the energy rather than just its variance.

What this PR changed, box by box

StageChangeWhy it matters
operator.py new Absorbed the orphaned mapping/. Filters diagonal terms before grouping and relabels groups into a canonical order, so a seeded qDRIFT draw is reproducible across processes — previously it diverged even between two calls in one process.
sqdrift.py moved seam Emits bare evolution circuits when include_initial_state=False, so one generated circuit can be sampled from different reference states. Verified equivalent to the old baked-in route (identical counts).
prep.py new Owns the reference determinant: explicit bitstring → Hartree-Fock → already-included. This is the stage that used to not exist.
sampler.run() widened Takes the whole ensemble in one submission and returns one counts dict per circuit. sample() remains as a single-circuit shim.
merge_counts() new Pools the ensemble. Previously solve() used circuits[0] and silently discarded N−1. At a fixed 20k-shot budget, 4 pooled randomizations improved SQD−FCI from 1.67e-04 → 4.34e-06 Ha.
counts.py, backend.py deduped One counts reader instead of two that disagreed on their return type; backend resolution and ISA transpile lifted out of the samplers, so a batch shares one pass manager.
Mock path no circuits requires_circuit = False replaces a brittle class-name check, so replay runs skip circuit construction entirely and need no qiskit-fermions.

One gotcha worth knowing

Two filters sound alike and are not the same knob:

  • filter_diagonal_terms prunes the operator before grouping — this is what makes seeded draws reproducible.
  • filter_trivial rejects individual draws during sampling. The pass reads the occupation from the reference state, so it only has an effect when that state is inside the circuit; it now defaults to wherever include_initial_state points.

The bitstring convention also bites: initial_state_bitstring is MSB-left, so the rightmost n_orbitals characters are the alpha block — mirrored from how it reads. A symmetric case (n_alpha == n_beta) hides a swapped block; an asymmetric one does not. Get it backwards and SQD postselects every shot away.
